# VolunNet

VolunNet is a Volunteer Coordination Platform backend built using Node.js, Express.js, MongoDB, JWT authentication, Firebase Cloud Messaging, and Socket.io.

## Features

- User registration and login
- JWT authentication
- Role-based authorization
- Volunteer and Admin roles
- Event management
- Volunteer event signups
- Volunteer hours tracking
- Impact reports
- Event reports
- Firebase push notifications
- Real-time notifications using Socket.io
- Request validation using express-validator

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Firebase Admin SDK
- Firebase Cloud Messaging (FCM)
- Socket.io
- express-validator
- Thunder Client
